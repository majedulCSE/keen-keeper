## What It Does 🧠

**KeenKeeper** is a modern, elegant friendship management platform that helps you stay intentionally connected with your important people.

It allows you to track interactions (calls, texts, video calls), visualize your engagement over time, and never let a meaningful relationship fade due to a busy schedule.

Built with **Next.js**, it delivers a fast, responsive and delightful user experience across all devices.




## What You'll Love ❤️

**Your people, front and center** The homepage shows your friends in a clean, personal layout — not a cold contact list, but a living snapshot of your social world.

**Friend cards that feel personal** Each card carries everything that matters: who they are, what they mean to you (via tags), your contact goal, and one-tap actions to call, text, or jump on a video call right away.

**A timeline of your relationship history** Scroll through every interaction — calls, texts, video chats — and filter or search however you like. It's like a memory of your friendships, laid out clearly.

**Charts that tell your story** Beautiful, color-coded graphs built with Recharts show you how your engagement has changed over time. Are you calling more? Texting less? The data is honest, and that's the point.

**Works everywhere you are** Whether you're on your phone between meetings or at your desk on a Sunday morning, KeenKeeper looks and feels great on every screen.

**Small details that make it delightful** Smooth animations, instant toast notifications when you take an action, and fast page loads thanks to Next.js — it's the kind of app that just feels nice to use.

## Run It Yourself 🚀

```bash
# Clone the repository
git clone https://github.com/majedulCSE/keen-keeper

# Navigate to the project directory
cd keen-keeper

# Install dependencies
npm install

# Start the development server
npm run dev 
```
